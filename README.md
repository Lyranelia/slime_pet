# Slimey Desktop Pet
This is the source code for a desktop pet written in Python.
The pet itself is available [on itch.io](https://lyranelia.itch.io/slimey-desktop-pet).

### What can it do?
It moves above your taskbar on your main monitor.
If you click on it, it looks to the sides and moves on.
It can have three sizes, which are generated randomly at execution.
It can have one of five colors, which are also chosen randomly at execution.
I am currently working a menu for selecting a specific size and color.
